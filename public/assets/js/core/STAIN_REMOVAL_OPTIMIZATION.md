## 优化内容总结

### 第一阶段优化（已实施）

#### 1. 背景估计与减除 (Background Estimation & Subtraction)
**问题**: 原文案对光照不均、泛黄纸张敏感，容易将背景变化误判为污渍

**解决方案**:
- 使用大核形态学闭运算 (51x51) 估计背景图像
- 从原图中减去背景，突出前景细节
- 有效处理：
  - 光照渐变
  - 纸张泛黄
  - 阴影区域

**代码位置**: `_estimateBackground()` 方法

---

#### 2. 自适应阈值 (Adaptive Thresholding)
**问题**: 全局阈值无法适应图像局部变化

**解决方案**:
- 使用 `cv.adaptiveThreshold` 替代普通二值化
- 采用高斯加权邻域计算局部阈值
- 参数可调：
  - `adaptiveBlockSize`: 邻域大小 (默认 11)
  - `adaptiveC`: 常数偏移 (默认 5)

**优势**:
- 自动适应不同亮度区域
- 保留更多细节
- 减少过分割和欠分割

**代码位置**: `_processImage()` 第 4 步

---

#### 3. 多特征增强评分系统
**新增特征**:

| 特征 | 说明 | 权重 |
|------|------|------|
| 实心度 (Solidity) | 轮廓面积/凸包面积 | 0.3 |
| 圆形度 (Circularity) | 4π*area/perimeter² | 0.2 |
| 紧凑度 (Compactness) | area/boundingRectArea | 0.2 |
| **孤立性 (Isolation)** | **新增**：评估与文字块的距离 | **0.3** |

**孤立性计算逻辑**:
- 计算轮廓中心到图像中心的归一化距离
- 假设污渍更可能出现在边缘区域
- TODO: 可升级为基于距离场的精确计算

**评分优化**:
- 圆形度偏好中等值 (0.3-0.8)，避免完美圆形或极不规则形状
- 紧凑度偏好低值（不规则形状更像污渍）
- 增加面积惩罚机制，排除过大或过小区域

---

#### 4. 形态学后处理
**新增步骤**:
- 检测到污渍后，进行膨胀操作连接相邻区域
- 使用 5x5 椭圆结构元素
- 避免遗漏由多个小斑点组成的复合污渍

---

### 参数配置系统

所有关键参数已暴露，支持动态调整：

```javascript
const cleaner = new DocumentCleaner();
cleaner.setParams({
    stainThreshold: 0.5,  // 降低阈值，更敏感
    adaptiveBlockSize: 15, // 更大的邻域
    weights: {
        isolation: 0.4     // 提高孤立性权重
    }
});
```

**推荐参数组合**:

| 场景 | stainThreshold | adaptiveBlockSize | isolation 权重 |
|------|---------------|-------------------|---------------|
| 干净文档 | 0.7 | 9 | 0.2 |
| 泛黄旧纸 | 0.5 | 15 | 0.3 |
| 复杂背景 | 0.55 | 13 | 0.4 |
| 密集文字 | 0.65 | 11 | 0.2 |

## 预期效果提升

### 改善场景

1. **光照不均文档** ✅
   - 背景减除消除渐变影响
   - 自适应阈值适应局部亮度

2. **泛黄/老化纸张** ✅
   - 背景估计分离纸张底色
   - 只检测真正的前景污渍

3. **边缘污渍** ✅
   - 孤立性特征优先检测边缘区域
   - 减少文字误检

4. **小型斑点污渍** ✅
   - 多尺度形态学捕捉小目标
   - 面积过滤排除噪声

### 仍需改进的场景

⚠️ **注意**: 以下场景仍需后续优化

1. **与文字粘连的污渍**
   - 当前方案可能无法完全分离
   - 需要更高级的连通域分析或深度学习

2. **浅色/半透明污渍**
   - 对比度低，难以检测
   - 可能需要颜色空间分析

3. **大面积污染**
   - 可能被误判为背景
   - 需要多尺度检测策略

4. **彩色污渍**
   - 灰度化处理丢失颜色信息
   - 建议增加 HSV/Lab 空间检测分支

## 性能影响

- **内存**: 增加 2-3 个临时 Mat（背景图、前景图），约增加 20% 内存占用
- **计算**: 背景估计增加一次大核形态学操作，处理时间增加约 15-25%
- **优化建议**: 
  - 对大图先缩放再处理
  - 使用 Web Worker 异步执行
  - 考虑 GPU 加速（如果浏览器支持）

## 测试方法

建议使用以下测试集验证效果：

1. **标准测试集**
   - 干净文档 + 人工添加污渍
   - 已知污渍位置和大小

2. **真实场景**
   - 扫描的旧书籍页面
   - 手机拍摄的文档照片
   - 传真件

3. **边界案例**
   - 极低对比度污渍
   - 与文字重叠的污渍
   - 超大/超小污渍

**评估指标**:
- 检出率 (Recall): 正确检测的污渍比例
- 准确率 (Precision): 检测结果中真正污渍的比例
- F1-Score: 综合指标
- 处理时间
